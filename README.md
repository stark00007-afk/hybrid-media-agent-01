
# HMA-01
## Autonomous Media Automation System

Version: 1.0
Status: Development

### Mission

Build an AI-powered media operation that researches,
creates, brands and distributes original content.

### Content Categories

1. Technology
2. Gaming
3. Entrepreneurship

### Publishing Schedule

Timezone: Asia/Kolkata

Morning:
- Preview: 08:30 AM
- Publish: 09:00 AM

Evening:
- Preview: 05:30 PM
- Publish: 06:00 PM

### Approval System

- Each post has an independent cancellation window.
- Cancellation window: 30 minutes.
- Only the authorized owner can cancel.
- Cancelled posts must never publish.
- Failed approval checks must prevent publishing.

### Platforms

- Instagram
- YouTube
- Facebook
- Discord (internal control centre)

### AI Components

- Research Agent
- Gemini Intelligence Engine
- Creative Agent
- Branding Engine
- SEO Engine
- Publishing Engine
- Analytics Engine

### Branding

Temporary brand identity: HMA MEDIA

Every post must contain consistent branding.

### Commercial Module

Future sponsorship management:
- Campaign enquiries
- Promotional content
- Human approval
- Performance reporting

### Human Editing Team

Reserved for Part 2.

### Security

- API keys stored as environment secrets.
- No credentials inside source files.
- Owner-only cancellation controls.
- Publishing fails closed if approval cannot be verified.

### Development Rules

- Build one component at a time.
- Test every component.
- Never publish unverified claims.
- Maintain source attribution.
- Never publish cancelled content.
